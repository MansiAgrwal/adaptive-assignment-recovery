# Step 2: Randomized recovery

**Question.** Before adding adaptive assignment, can the joint-minus-single gain be recovered in a simple design? Each person gets one randomly assigned activity, with tests before and after.

## Results

**`anchor_recovery.py`**: 600 simulated datasets, 100 per cell, at N = 300, 600 and 1,200, with and without persistent learner types. The model estimates measurement error, starting states and 4 × 4 transition matrices by EM with three random starts. `summarize_recovery.py` produces `Recovery_Contrast_Diagnostics.csv`.

| N | Learner types | Sampling SD of the rule-*a* contrast |
|---:|---|---:|
| 300 | one | 0.081 |
| 300 | two | 0.085 |
| 1,200 | one | 0.041 |
| 1,200 | two | 0.037 |

The simulated effects here are about ±0.07–0.08. Bias was within two Monte Carlo SEs of zero in every cell. At N = 300, though, the sampling SD (about 0.08) is as large as the effect itself, so the contrast is recovered without detectable bias but imprecisely. **Interval coverage was not evaluated.**

**`participant_recovery.py`**: 1,800 datasets in which each person completes 3 or 6 independent randomized episodes, at 180, 240 and 300 people. More episodes per person improved precision. Each episode starts from a fresh competence state, so this is **not** a continuing learning process. `Repeated_Context_Diagnostics.csv` marks this explicitly.

**`heterogeneity_counterexample.py`**: an exact calculation with fractions and no measurement error. Half the learners are fast and half slow, and all start unmastered. Among learners still unmastered, the next-step gain depends on which activities they have already had, because fast learners leave the unmastered group sooner. One average transition matrix from a one-shot design therefore cannot describe repeated practice. Step 3 models learner types directly for this reason.

**`design_checks.py`**: small exact checks.
- With known measurement, the reference design's transitions can be recovered exactly.
- With endpoint-only tests, two different gain patterns produce identical data, so endpoint-only designs can fail.
- Under a fully logged adaptive rule with every activity possible, the likelihood factorises as expected.
- The EM implementation passes likelihood arithmetic checks.

None of these is offered as a new theorem.

## Reproduce

```bash
python anchor_recovery.py --reps 100 --ns 300 600 1200 --starts 3 --output anchor_recovery_results.json
python summarize_recovery.py
python participant_recovery.py --people 180 240 300 --episodes 3 6 --reps 100 --output participant_recovery_results.json
python summarize_participant_recovery.py
python heterogeneity_counterexample.py
python design_checks.py
```

Both recovery scripts draw every cell from one random stream, so a single replication can only be regenerated by re-running the whole grid with these arguments.
